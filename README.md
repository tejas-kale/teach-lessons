# Learning Vault

This repository is an Obsidian vault. Notes hold the learning record, and Obsidian Bases supplies the views.

Start at [[Home]]. The active course is [[ICE-ing the Economy]]. This vault records what Tejas has done and the evidence it produced.

## Operating rule

At the end of a study sitting, update only the unit you touched:

1. Change `status` to `complete` only when the stated outcome has been demonstrated.
2. Add a link or one sentence under **Evidence**.
3. Put exactly one concrete next step in `next_action`.

Do not update a separate percentage. The [[Progress.base]] views derive the current picture from unit notes.

## Setup in Obsidian

1. Open this repository folder as a vault.
2. Enable the built-in **Bases**, **Daily notes**, and **Templates** plugins.
3. Set Templates' folder to `Templates` and Daily notes' template to `Templates/Template - Daily Study Note`.
4. Open [[Home]] and pin it.

The vault uses ordinary Markdown and YAML frontmatter; it remains useful in any editor and can stay in Git.
