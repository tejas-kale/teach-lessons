# Self-Improving AI Agents — a teaching workspace

Stanford's [CS329A *Self-Improving AI Agents*](https://www.youtube.com/playlist?list=PLangBM27OtEA) (Fall 2026, Mirhoseini & Tandon), re-cut into fourteen short lessons for a **practitioner** — someone who uses agents daily and wants to tune them, measure them, and stay current, not publish papers.

Every lesson ends with a dial to turn or a number to collect.

## Start here

```sh
open index.html
```

## The arcs

| Arc | Lessons | Question it answers |
|-----|---------|---------------------|
| I · The map and the dial | 1–3 | Where does improvement come from now, and which levers are mine? |
| II · Verification | 4–7 | How do I tell a good output from a bad one, when there is no test? |
| III · Getting better over time | 8–11 | How do agents plan, learn from experience, and when is fine-tuning warranted? |
| IV · Measuring it | 12–14 | How do I know any of this worked? |
